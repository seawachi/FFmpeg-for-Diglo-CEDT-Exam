# คู่มือบันทึกวิดีโอด้วย FFmpeg

สคริปต์นี้ใช้บน macOS เพื่อบันทึกวิดีโอจากอุปกรณ์ AVFoundation เป็นไฟล์ MP4 โดยบันทึกไว้ในโฟลเดอร์ `videos` ที่อยู่ข้างสคริปต์

> **จุดเด่น: ป้องกันไฟล์ถูกเขียนทับ** สคริปต์ตรวจสอบไฟล์เดิมและกำหนดหมายเลขวิดีโอถัดไปให้อัตโนมัติ เช่น `_0`, `_1`, `_2` จึงบันทึกซ้ำได้โดยไม่ต้องตั้งชื่อเอง

## ตั้งค่าครั้งแรก

1. เปิดแอป **Terminal** แล้ว cd เข้าไปยังโฟลเดอร์ที่มี `record_screen.sh`
2. เรียกสคริปต์:

   ```bash
   ./record_screen.sh
   ```

3. หากยังไม่ได้ติดตั้งไลบรารีหรือโปรแกรมที่จำเป็น ให้รันสคริปต์ได้เลย สคริปต์จะแสดงคำสั่งติดตั้งที่ต้องใช้ใน Terminal คัดลอกคำสั่งไปรันทีละคำสั่ง รอให้ติดตั้งเสร็จ แล้วเรียก `./record_screen.sh` อีกครั้ง
4. เมื่อเริ่มใช้งานครั้งแรก ให้กรอกรหัสนักศึกษา
5. เลือกหมายเลขกล้องหรืออุปกรณ์วิดีโอจากรายการ

รหัสนักศึกษาและหมายเลขอุปกรณ์จะถูกบันทึกใน `settings.conf` ข้างสคริปต์ ในการใช้งานครั้งถัดไป เลือกใช้กล้องเดิมหรือเลือกกล้องอื่นได้ หากต้องการกรอกรหัสนักศึกษาใหม่ ให้ลบ `settings.conf` แล้วเรียกสคริปต์อีกครั้ง

หาก macOS ขอสิทธิ์เข้าถึง ให้เปิด **System Settings → Privacy & Security → Screen & System Audio Recording** แล้วอนุญาตให้ Terminal บันทึกหน้าจอหรือใช้อุปกรณ์ที่เลือก ชื่อเมนูอาจต่างกันตามเวอร์ชัน macOS

## บันทึกวิดีโอ
<img width="770" height="346" alt="image" src="https://github.com/user-attachments/assets/77674ef5-dd9f-430b-95a3-5608fc1e194c" />

เรียกสคริปต์จาก Terminal:

```bash
./record_screen.sh
```

กรอกประเภทควิซและหมายเลขควิซเมื่อสคริปต์ถาม เช่น `exam` และ `1` หน้าจอจะแสดงตำแหน่งไฟล์ และ FFmpeg จะแสดงความคืบหน้ากับเวลาที่บันทึกอยู่

- หยุดและบันทึกไฟล์: กด **q** ในหน้าต่าง Terminal ที่กำลังบันทึก
- อย่าปิดหน้าต่าง Terminal จนกว่าจะเห็นข้อความ **RECORDING SAVED**
- หลังบันทึกเสร็จ สคริปต์จะแสดงตำแหน่งไฟล์ที่บันทึก

## วิธีดั้งเดิม: รัน FFmpeg โดยตรง

หากต้องการสั่ง FFmpeg เองโดยไม่ใช้สคริปต์ ให้เปิด Terminal แล้วรันคำสั่งนี้:

```bash
ffmpeg -f avfoundation -i "5" -r 2 -probesize 40M -vcodec libx264 -b:v 256k -threads 1 ./test.mp4
```

เปลี่ยน `5` เป็นหมายเลขอุปกรณ์วิดีโอที่ต้องการ และเปลี่ยน `test.mp4` เป็นชื่อไฟล์ที่ต้องการ กด `q` ใน Terminal เพื่อหยุดและบันทึกไฟล์ วิธีนี้ไม่ตั้งชื่อไฟล์อัตโนมัติและไม่ป้องกันการเขียนทับไฟล์เดิม

## บันทึกหลายไฟล์พร้อมกัน

เปิด Terminal แยกสองหน้าต่าง แล้วเรียก `./record_screen.sh` ในแต่ละหน้าต่าง เลือกอุปกรณ์วิดีโอคนละตัวเพื่อบันทึกเป็นไฟล์แยกกัน สคริปต์จะจองหมายเลขไฟล์ให้แต่ละรอบ จึงไม่ใช้ชื่อไฟล์ซ้ำ

กล้องบางรุ่นไม่รองรับการบันทึกพร้อมกัน หากเปิดกล้องเดียวกันแล้วเกิดข้อผิดพลาด ให้เลือกคนละอุปกรณ์

## ตำแหน่งและชื่อไฟล์

ไฟล์จะอยู่ในโฟลเดอร์ `videos` และตั้งชื่อตามรูปแบบ:

```text
<รหัสนักศึกษา>_<ประเภทควิซ><หมายเลขควิซ>_<หมายเลขวิดีโอ>.mp4
```

หมายเลขวิดีโอเริ่มที่ `0` สคริปต์จะหาเลขถัดไปที่ยังไม่มีไฟล์อยู่โดยอัตโนมัติ หากไฟล์เลขนั้นมีอยู่แล้ว จะข้ามไปใช้เลขถัดไป จึงไม่เขียนทับวิดีโอเดิม ตัวอย่างการบันทึกควิซ exam หมายเลข 1 สองไฟล์:

```text
videos/6933123456_exam1_0.mp4
videos/6933123456_exam1_1.mp4
```

## ค่าการบันทึก

บันทึกที่ 2 เฟรมต่อวินาที ใช้ตัวเข้ารหัส H.264 บิตเรตวิดีโอ 256 kb/s และเธรดเข้ารหัส 1 เธรด
